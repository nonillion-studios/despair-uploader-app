# Despair Uploader App

تطبيق سطح مكتب (Tauri) للأدمن ومساعديه -- رفع فصول مانجا/روايات، وإنشاء أعمال أنمي عن طريق AniList، مباشرة لـ despair-world.com.

## طريقة الحصول على نسخة قابلة للتثبيت

كل Push على فرع `main` بيشغّل GitHub Action يبني نسخة Windows تلقائيًا وينشرها في تبويب **Releases** بالريبو -- حمّل ملف `.exe` من هناك، ركّبه، وافتح التطبيق.

## الإعداد عند أول تشغيل

1. افتح التطبيق.
2. روح لوحة تحكم الموقع (أدمن) → "مفاتيح تطبيق الرفع" → ولّد مفتاح جديد.
3. الصق المفتاح في خانة "مفتاح API" في التطبيق واضغط "حفظ المفتاح".

## التطوير محليًا (يحتاج Rust + Node مثبتين)

```bash
npm install
npm run tauri dev
```
